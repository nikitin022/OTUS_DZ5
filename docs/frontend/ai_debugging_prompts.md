# AI-промпт-шаблоны для тестирования и отладки

> Шаблоны для работы с AI-агентом (в том числе мультимодальными моделями)
> при поиске и исправлении багов в проекте «Капля».

## 1. Анализ скриншота бага (мультимодальная модель)

```text
Контекст: PWA «Капля» — React 18 + TypeScript + Tailwind CSS v4,
стиль Minimalist, mobile-first от 320px. Экран: <название экрана>.
Ожидаемое поведение: <ссылка на FR/NFR из technical_specification.md>.

Приложен скриншот. Разбери баг строго по схеме:
1. Факты: что видно на скриншоте (текст, разметка, отступы, цвета).
2. Расхождение: чем отличается от ожидаемого поведения по ТЗ.
3. Гипотеза: вероятная причина (компонент, состояние, CSS-класс, данные).
4. Шаги воспроизведения: минимальная последовательность действий.
5. Исправление: файл(ы) и суть изменения.

Ограничения:
- стилизацию менять только через дизайн-токены из src/index.css;
- не менять публичный контракт ApiClient;
- язык интерфейса — русский, тон Minimalist.
```

## 2. Интерпретация ошибки из консоли

```text
Вот ошибка из консоли браузера при работе приложения «Капля»:

<текст ошибки / стектрейс>

1. Объясни суть ошибки простыми словами.
2. Определи источник по стектрейсу (файл, компонент, модуль).
3. Перечисли гипотезы причины — от наиболее к наименее вероятной.
4. Предложи минимальное исправление.
5. Напиши тест (Vitest + React Testing Library), который воспроизводит
   эту ошибку до исправления и проходит после.

Контекст проекта: см. rules.md и docs/stack_decision.md.
```

## 3. Генерация исправления по тесту

```text
Баг: <краткое описание симптома>.
Воспроизводится тестом: <путь к тест-файлу, название теста>.
Ожидаемое поведение: <ссылка на FR из ТЗ>.

Требования к исправлению:
1. Минимальное изменение, чтобы тест прошёл.
2. Не менять контракт ApiClient и модели данных без необходимости.
3. Соблюдать правила из rules.md (архитектура, UX, стилизация).
4. Добавить регрессионный тест, если его ещё нет.
5. После исправления: npm run build, npm run test, npm run lint — без ошибок.
```

## 4. Регрессионный прогон после фикса

```bash
npm run test    # все тесты, включая новый регрессионный
npm run lint    # без ошибок
npm run build   # сборка и проверка типов
```
