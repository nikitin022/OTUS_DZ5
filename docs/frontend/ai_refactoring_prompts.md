# Рефакторинг и оптимизация с AI-агентом

> Шаг разработки: оптимизация и рефакторинг. Исходное состояние: 79 тестов
> зелёные, бандл 451 КБ (gzip 138,8 КБ), main-чанк содержит Leaflet.

## 1. Использованные промпты и техники

| Этап | Промпт / техника | Результат |
|---|---|---|
| Аудит дублирования | «Найди в src/ повторяющиеся паттерны: одинаковые блоки isPending/isError в страницах, повторяющиеся строки классов, повторный поиск центров через .find()» (grep по кодовой базе + сводка) | 7 блоков скаффолдинга, 7 копий классов кнопок-ссылок в 6 файлах, 3 самостоятельных .find() |
| Проектирование примитива | «Спроектируй декларативный компонент состояний экрана (загрузка/ошибка/успех) поверх TanStack Query: API должен сохранить индивидуальные сообщения экранов и не ломать шапку с кнопкой "Назад"» | `PageGate` с пропами `queries`, `header`, `skeleton`, `errorMessage`, `children` |
| Устранение дублей стилей | «Извлеки общие стили вариантов Button в модуль и переиспользуй их в кнопке-ссылке» | `buttonVariants.ts` + `LinkButton` |
| Производительность | «Определи самый тяжёлый модуль бандла и вынеси его в ленивый чанк; дай измеримую метрику до/после» | `React.lazy` для `MapPage` (Leaflet) |
| Верификация | «Прогони тесты, сборку, линт; проверь в браузере, что все экраны сохраняют шапку и не дублируют её» | Нашёл баг отсутствия шапки в состоянии успеха (см. раздел 2) |

Наиболее эффективные техники:

1. **Метрики до/после** — цель рефакторинга формулировалась измеримо
   (размер чанков), а не «стало лучше»;
2. **Тесты как страховка** — 79 существующих тестов определили критерий
   «поведение не изменилось»; новые компоненты сразу покрыты тестами
   (`PageGate`, `LinkButton`);
3. **Аудит по структурным паттернам** (grep одинаковых классов/блоков),
   а не по догадкам — дублирование находилось объективно;
4. **Отказ от рефакторинга там, где он ухудшает код** — `FeedPage` со своей
   логикой «данные устарели + частичный сбой» сознательно оставлен без
   `PageGate`: обобщение сломало бы специфичное поведение.

## 2. Возникшие проблемы и решения

| Проблема | Как обнаружена | Решение |
|---|---|---|
| `PageGate` не рендерил `header` в состоянии успеха — шапки экранов пропадали | Браузерная проверка после рефакторинга: на записи/истории/заявке нет h1 | Ветка успеха тоже рендерит `header`; тест успеха дополнен проверкой шапки |
| Двойной `PageHeader` в карточке центра | Ревью diff: заголовок зависит от данных центра | Шапка передана через `header` в `PageGate`, детальная часть — отдельно |
| TS-ошибки после выделения `BookingForm` (тип донора `Donor \| null`) | `tsc --noEmit` | Тип пропса ослаблен до `Donor \| null` с комментарием про FR-1.4 |
| Warning `react-refresh/only-export-components` в `router.tsx` | `npm run lint` | Компонент fallback'а инлайнен в `Suspense` |
| Отвязка dev-сервера при длинной сессии | `ERR_CONNECTION_REFUSED` | Перезапуск `npm run dev` фоном |
