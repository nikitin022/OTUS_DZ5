# Правила работы AI-агента — проект «Капля»

## О проекте

«Капля» — PWA для доноров крови: карта центров, живая лента потребностей,
push-уведомления по профилю донора, запись на донацию. Полные требования:
`technical_specification.md`, `docs/functional_requirements.md`.

## Стек

- React 18 + TypeScript (strict) + Vite;
- Tailwind CSS v4 (конфигурация через `@theme` в `src/index.css`, без `tailwind.config`);
- Leaflet + react-leaflet (карта), TanStack Query (серверное состояние), React Router v6;
- vite-plugin-pwa (Service Worker, manifest), Vitest + React Testing Library.

## Архитектурные правила

- Доступ к данным — только через интерфейс `ApiClient` (`src/api/ApiClient.ts`);
  прямой импорт mock-хранилища в компонентах запрещён.
- Экраны и логика по фичам: `src/features/<модуль>/ui`, `.../model`, `.../api`.
- Общие компоненты — `src/components/ui`, модели данных — `src/types`.
- Все модели данных типизированы; `any` запрещён.

## UX-правила

- Язык интерфейса — русский, понятные сообщения без жаргона.
- Стиль Minimalist, mobile-first, адаптивность от 320px.
- Контраст текста и фона — не ниже WCAG AA (4.5:1); палитра — токены из `src/index.css`.
- Красный (`danger-600`) — только для блокирующих ошибок и статусов «Срочно/Критично».
- Обязательная матрица обработки ошибок: валидация (подсветка + текст под полем),
  пустые состояния с действием, сетевые ошибки (скелетон, «Нет соединения» + «Повторить»),
  гостевой доступ к просмотру.

## Код

- Функциональные компоненты + хуки; без классов.
- Именование: компоненты и их файлы — PascalCase, хуки и утилиты — camelCase,
  константы — UPPER_SNAKE_CASE.
- Каждый экспортируемый компонент/функция — краткий JSDoc-комментарий.

## Процесс

- Коммиты по Conventional Commits: `feat:`, `fix:`, `chore:`, `docs:`.
- Каждый завершённый шаг работы — коммит и пуш в `origin/main`.
- Перед коммитом: `npm run build`, `npm run test`, `npm run lint` — без ошибок.
